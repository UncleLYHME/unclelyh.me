# Site Navigation

Use this skill when you need structured access to content on https://unclelyh.me.

## What this site exposes

- Markdown homepage: `https://unclelyh.me/` with `Accept: text/markdown`
- llms.txt: `https://unclelyh.me/.well-known/llms.txt`

## Guidance

- Prefer the markdown homepage for summarization tasks.
- Use the homepage sections and `llms.txt` for profile, skills, experience, and project listings.
- Use canonical links when citing the site: `https://unclelyh.me`.
